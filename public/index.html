How it works

A pipeline with real data-quality gates.

Paged Socrata requests with retries and a parquet cache, pandas cleaning, a pandera schema that rejects bad rows before they reach the warehouse, and a read-only DuckDB connection behind every query.

Features

Built like production, small enough to run locally.

📡

Resilient ingestion

Pages through the Socrata SODA API with retries, exponential backoff, and a local parquet cache.

🛡️

Data-quality gates

A pandera schema enforces types, value ranges, NYC geo-bounds, and uniqueness before loading.

🦆

Columnar warehouse

Cleaned data lands in DuckDB for fast analytical SQL, opened read-only by the dashboard.

📊

Interactive dashboard

Monthly trends, contributing factors, vehicle types, and a 20k-point crash map with filters.

🤖

Ask the data

Plain-English questions become SQL through Claude, with SELECT-only guardrails and a read-only connection.

✅

Tested & CI'd

A pytest suite covers transforms, validation, and SQL guards; GitHub Actions runs it on every push.

Ask the data

Question in, SQL and results out.

You ask Which borough had the most cyclist injuries in 2024?

Claude writes a single SELECT statement, the app explains it, runs it on the read-only warehouse, and returns the table — no SQL required. 

-- generated by Claude, guarded to SELECT-only
SELECT borough,
       SUM(cyclists_injured) AS injuries
FROM crashes
WHERE crash_year = 2024
GROUP BY borough
ORDER BY injuries DESC
LIMIT 5;

Quickstart

Run the whole thing in four commands.

  1. Create an environment and install the dependencies.
  2. Run the pipeline with --limit 100000 for a quick first pull.
  3. Launch the dashboard with Streamlit.
  4. Optional: set ANTHROPIC_API_KEY to enable AI querying.
# 1. install
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -e .

# 2. build the warehouse
python -m crashlens.pipeline --limit 100000

# 3. launch
streamlit run app/dashboard.py

Host the dashboard

The interactive app runs on Streamlit Community Cloud (this page is the static project overview, hosted on Vercel). A 100k-row demo warehouse ships with the repo, so the app boots with data on the first run.
